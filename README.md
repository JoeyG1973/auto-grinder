# Auto Grinder File Server

A simple GitHub Pages-powered file server for the Auto Grinder project. This repository serves files directly to the internet using GitHub's static hosting capabilities.

## 🌐 Live Site

Visit the file server at: **https://joyg1973.github.io/auto-grinder**

## 📁 What's Included

- **Arduino Code**: Download the latest Auto Grinder firmware files
- **Project Files**: Access documentation, schematics, and other project resources
- **File Browser**: Simple web interface for browsing and downloading files

## 🚀 How It Works

This repository uses GitHub Pages to serve static files. Any file uploaded to the repository becomes accessible via web browser:

- Main page: `https://joyg1973.github.io/auto-grinder/`
- Files directory: `https://joyg1973.github.io/auto-grinder/files/`
- Direct file access: `https://joyg1973.github.io/auto-grinder/files/filename.ext`

## 📤 Adding Files

1. Upload files to the `files/` directory
2. Commit and push changes to GitHub
3. Files become immediately available via the web interface
4. Update `files/index.html` to add file descriptions (optional)

## 🛠️ Arduino Files

The repository includes Arduino code for the Auto Grinder project:

- `auto_grinderv7.ino` - Latest version
- `grinder_autov5.ino` - Previous version
