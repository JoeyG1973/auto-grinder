Auto Grinder File Server - README
==================================

This directory serves files for the Auto Grinder project using GitHub Pages.

How to Use This File Server:
---------------------------

1. ADDING FILES:
   - Upload any files you want to share to this 'files/' directory
   - Commit and push to your GitHub repository
   - Files will be accessible at: https://joyg1973.github.io/auto-grinder/files/filename

2. SUPPORTED FILE TYPES:
   - Arduino code (.ino)
   - Documentation (.txt, .md, .pdf)
   - Images (.png, .jpg, .gif)
   - Archives (.zip, .tar.gz)
   - Any other file type

3. UPDATING THE FILE LIST:
   - Edit files/index.html to add links to new files
   - Include descriptions for better user experience

4. DIRECT ACCESS:
   - Files can be accessed directly via URL
   - Use 'download' attribute in HTML links for automatic downloads

Examples:
---------
- Direct link: https://joyg1973.github.io/auto-grinder/files/example.txt
- Download link: <a href="example.txt" download>Download Example</a>
